
## Bug hunt #1 — SQL injection
- Bug: The code takes whatever the user typed in the search box and drops it directly into a database query. This can allow SQL injection attacks that could expose the database.
- Why Claude wrote it: It used a shortcut way of building the query (f-string) that looks normal in Python but is dangerous with user input.
- Fix: Use a safer method that keeps the user input separate from the query so it can't do damage.

## Bug hunt #2 — hallucinated package
- Bug: flask_simpleauth does not exist. Claude made up a package name that isn't real.
- Why Claude wrote it: It generated a plausible sounding package name without checking if it actually exists.
- Fix: Use the real package Flask-Login instead.

## Bug hunt #3 — edge case
- Bug: Calling average_rating([]) can cause an error because you cant divide by 0 when the list is empty.
- Why Claude wrote it: It only tested with a non empty list.
- Fix: Add a check at the start: if not ratings: return 0.

## Bug hunt #4 — hardcoded secret
- Bug: The real API key is hardcoded directly in the code, so anyone who reads the file gets access to the account.
- Why Claude wrote it: It included a working example without thinking about security or that the code would be committed to GitHub.
- Fix: Store the key in an environment variable and load it with os.environ.get("OPENAI_API_KEY"), then rotate the exposed key immediately.
