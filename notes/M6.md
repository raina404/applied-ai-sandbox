
## Copilot — installed
- Observation: Copilot autocompletes inline without reading project files or CLAUDE.md, so it's fast for boilerplate but doesn't know your project's rules.

## Gemini CLI — demo'd
- Same prompt comparison: Gemini CLI is the same shape as Claude Code but couldn't authenticate in WSL; based on the demo, Claude Code felt more reliable for codebase navigation while Gemini was faster to start up.

## Chat (Claude.ai) — used for code review
- Observation: Chat flagged that test-seeded notes don't have a tags key, which would cause a KeyError if any code tries to access note["tags"] on old notes.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | reads project conventions and CLAUDE.md |
| 5-line helper autocomplete while typing | Copilot | faster than writing a brief for one line |
| Brainstorm three design approaches | Chat | no code needed, just thinking |
| Review a teammate's PR for security issues | Chat | paste the diff, get a review instantly |
| Cross-file refactor with consistent renames | Cursor | inline multi-file diff is built for this |
| Learning a new library's API | Chat | explain and example without touching code |
